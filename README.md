## 📌 About This Repository  

This repository showcases my work for the **Computer Organization & Assembly Language (COAL)** course.  
It includes a collection of **lab exercises** and **assignments** focused on building a strong foundation in **low-level programming** using **x86 Assembly Language (MASM)**.

The goal is to understand how software interacts directly with hardware, memory, and processor instructions.

---

## 🧠 Concepts Covered  

✔ x86 Assembly Language (MASM)  
✔ CPU Registers & Instruction Set  
✔ Memory Addressing Modes  
✔ Stack Operations & Procedures  
✔ Macros & Modular Programming  
✔ Input/Output Handling (Irvine32)  
✔ Debugging & Optimization
